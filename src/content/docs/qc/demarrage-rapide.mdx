Le Mac Mini sort juste de sa boîte su ton bureau. Fond d'écran de base, zéro app, une petite puck d'aluminium ben innocente qui a aucune idée qu'a va bientôt gérer la charge de travail d'une MRC au complet. T'as un café chaud pis environ une période de hockey devant toi. Dans trente minutes, c'te boîte-là est vivante : a fait tourner un cerveau local de 27 milliards de paramètres, a backupe ta vie chiffrée chaque nuit pis a téléphone à exactement personne.

Pas d'IP statique. Pas de nom de domaine. Pas de rançon SaaS mensuelle. Maximum effort — on droppe la puck.

*Pour la version longue avec chaque cas limite, checke [Quick Start (EN)](/getting-started/quick-start/) pis [Installation (EN)](/getting-started/installation/).*

## C'qui faut su ton établi

Pour la bêta complète avec le Dragon local (Qwen3.8 27B quantifié 4-bit), ça prend un **Mac Apple Silicon avec 32 Go de mémoire unifiée**. Un Mac Mini ou un Mac Studio, c'est exactement la même recette. Un Mac de 16 Go peut ben installer le CLI pis les backups chiffrés, mais y rentrera pas le Dragon 27B dedans.

| Morceau | Minimum bêta | Setup de rêve bêta-testeur |
| :--- | :--- | :--- |
| Puce | Apple Silicon M2 | M4 Pro / M4 Max |
| Mémoire unifiée | 32 Go (16 Go sans Dragon) | 64 Go+ |
| Disque | 256 Go libres | 1 To+ interne |
| Réseau | Wi-Fi | Ethernet Gigabit |
| Bonus fine-tuning | Un seul Mac suffit | Mac Mini + bon MacBook Pro en tandem |

<Aside type="tip" title="Le duo Mac Mini + MacBook Pro en tandem">
  T'as un Mac Mini costaud dans le garde-robe pis un bon MacBook Pro su ton bureau? T'es exactement le genre de bêta-testeur qu'on cherche : le Mini tient le fort 24/7 pendant que ton MacBook Pro peut avaler des runs d'eval ou du fine-tuning local en tandem sans jamais ralentir la cabane.
</Aside>

Ça te prend aussi un compte [Cloudflare gratuit](https://dash.cloudflare.com/sign-up) (le niveau gratuit R2 de 10 Go sert aux backups chiffrés) pis une demi-heure tranquille. T'as **zéro** besoin d'IP statique, de domaine dédié, de compte Apple Developer ou d'abonnement Sanctum.

## Le speedrun en 6 étapes

<Steps>

1. **Part l'installeur Sanctum.** Y s'occupe d'installer Homebrew au besoin, `sanctum-cli`, `restic` pis Node.js signé :

   ```bash
   curl -fsSL https://sanctum.run/install.sh | bash
   ```

   Tu préfères checker le hash SHA-256 avant de coller un `curl | bash` (Windu te félicite) ou passer direct par Homebrew? Passe direct par le tap :

   ```bash
   brew install ogilthorp3/sanctum/sanctum-cli
   ```

   Su Homebrew 5.x, accepte le tap tiers une fois avec `brew trust --formula ogilthorp3/sanctum/sanctum-cli`.

2. **Confirme que `sanctum` répond.** Si tu vois `status`, `doctor`, `onboard`, `backup` pis `chat`, t'es en business :

   ```bash
   sanctum --version
   sanctum --help
   ```

   <Aside type="tip">
     Un Mac neuf peut te demander d'installer les Command Line Tools d'Apple. Laisse Apple finir pis relance la commande — l'installeur est idempotent.
   </Aside>

3. **Lance l'onboarding.** C'est là que la magie opère, en cinq chapitres guidés :

   ```bash
   sanctum onboard --recipe family
   ```

   - **Your AI** range si tu veux tes clés **Claude** pis **Gemini** dans le Keychain macOS. Saute c'te bout-là si tu veux rouler 100 % local.
   - **Your Network** sonde un pont Bell, Firewalla pis Orbi (facultatif su un bureau de test).
   - **Your Data** branche Cloudflare R2 chiffré, roule un vrai backup pis restaure un fichier canari pour prouver l'aller-retour.

   Quand le panneau vert s'allume avec ton prénom, prends une capture d'écran.

4. **Installe toute la suite moteur Rust (`sanctum-rs`) + le Dragon champion (`dragon-2`).** Une seule commande vérifie le SHA-256, déploie les **32 binaires Rust natifs signés Apple Developer ID + `mlx.metallib` + vecteurs d'ablation** (`sanctum-mlx`, `proxyd :4040`, `sanctum-presidio`, `sanctum-memory`, `castellan`, `sanctum-force-flow`, `sanctumd`, `sanctum-msg-bus`, `sanctum-chitti`, `sanctum-thalamus`, `sanctum-triage`, `sanctum-pressure-valve`, `sanctum-chi`, `memory-vault-mcp`, `sanctum-vault`), génère ta propre PKI mTLS + clé Keychain par machine, télécharge le **Dragon 27B + adaptateur champion (`193d2d7407ec`)** su 32 Go+ (**+ cathédrale Coder 9B su `:3301` dès 64 Go**, ou **Qwen3.5-9B** su 16 Go) pis démarre jusqu'à 16 LaunchAgents automatiquement (incluant Memory Vault, Endocrine et R2D2) :

   ```bash
   sanctum haus install
   sanctum haus status
   sanctum council        # ouvre la chambre du Conseil Jedi direct su ton moteur Rust!
   ```

   Le premier coup télécharge ~15 Go de poids HuggingFace (ou ~5,5 Go en 9B). *(Tu peux aussi rouler `sanctum dragon install --runtime python` si tu veux juste le petit venv `mlx-lm`.)*

5. **Branche Yoda sur Signal (facultatif, recommandé!).** L'assistant installe les dernières versions de `signal-cli`, `openclaw` pis `@openclaw/signal`, te guide pour appairer un numéro Signal dédié pour Yoda (QR ou SMS), pis branche Yoda direct su ton **`proxyd` Rust (`https://127.0.0.1:4040/v1`) → `sanctum-presidio` → `sanctum-mlx` mTLS `:1337`** :

   ```bash
   sanctum yoda setup
   ```

   <Aside type="note" title="Pourquoi un numéro dédié pour Yoda?">
     Signal bloque les boucles si un bot tourne su ton propre numéro personnel (tes propres messages sont ignorés). Un petit numéro prépayé / eSIM dédié règle ça proprement en deux minutes.
   </Aside>

6. **Passe le check-up complet — pis mets TOUT à jour en 1 commande quand une nouvelle version sort :**

   ```bash
   sanctum status
   sanctum haus status
   sanctum ui            # tableau de bord local 100 % privé (http://127.0.0.1:1119)
   sanctum haus seats    # branche tes abonnements $0 (Claude Max / Grok / Gemini)
   sanctum bug-report    # génère un diagnostic nettoyé et ouvre un billet GitHub
   sanctum update        # met à jour CLI + suite Rust sanctum-rs + Dragon + Yoda/Signal!
   ```

   Toute c'qui vire jaune ou rouge te dit drette quelle ligne réparer. Zéro théâtre de faux vert.

7. **Déballe le studio bundle (si t'en as reçu un).** Lance `./install.sh` puis `./yoda.sh hello` pour entendre ton Mac te parler en local, pis `./council.sh` pour appeler Windu, Qui-Gon, Cilghal, Mundi ou Mothma direct su ton Dragon.

</Steps>

## De quoi a brisé? Dis-nous-le sans gêne

Le contrat est simple pis tient pas dans un EULA de quarante pages : ta cabane te mentira jamais pour protéger tes sentiments. Une lumière verte sans preuve en arrière, c'est du théâtre. Ouvre un billet su le [formulaire bêta `sanctum-cli`](https://github.com/Ogilthorp3/sanctum-cli/issues/new/choose) avec ta sortie `sanctum doctor` (secrets masqués) — on les lit toutes.

Quand ton panneau vert te salue, passe voir [L'Architecture en 5 minutes](/qc/architecture/), jette un œil au [Guide des parents](/parents-guide/qc/) pour gérer les écrans en famille, ou va saluer [Tommy](/qc/) qui veille au grain.
