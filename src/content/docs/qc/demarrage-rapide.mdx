Le Mac Mini sort juste de sa boîte sur ton bureau. Fond d'écran par défaut, zéro app, une petite rondelle d'aluminium innocente qui a aucune idée qu'elle s'apprête à gérer la charge de travail d'une petite municipalité. Tu as un café chaud pis environ une période de hockey devant toi. Dans trente minutes, cette boîte-là est vivante : elle fait tourner un cerveau local de 27 milliards de paramètres, sauvegarde ta vie chiffrée chaque nuit pis téléphone à exactement personne.

Pas d'IP statique. Pas de nom de domaine. Pas de rançon SaaS mensuelle. Maximum effort — on décolle.

*Pour la version intégrale avec chaque cas limite, voir [Quick Start (EN)](/getting-started/quick-start/) et [Installation (EN)](/getting-started/installation/).*

## Ce qu'il te faut sur la table

Pour la bêta complète avec le Dragon local (Qwen3.8 27B quantifié 4-bit), il faut un **Mac Apple Silicon avec 32 Go de mémoire unifiée**. Un Mac Mini ou un Mac Studio suivent exactement le même chemin. Un Mac de 16 Go peut très bien installer le CLI pis les sauvegardes chiffrées, mais il tiendra pas le Dragon 27B au complet.

| Composant | Minimum bêta | Idéal bêta-testeur |
| :--- | :--- | :--- |
| Puce | Apple Silicon M2 | M4 Pro / M4 Max |
| Mémoire unifiée | 32 Go (16 Go sans Dragon) | 64 Go+ |
| Espace disque | 256 Go libres | 1 To+ interne |
| Réseau | Wi-Fi | Ethernet Gigabit |
| Bonus fine-tuning | Un seul Mac suffit | Mac Mini + MacBook Pro costaud en tandem |

<Aside type="tip" title="Mode tandem Mac Mini + MacBook Pro">
  Si tu as un Mac Mini costaud dans le garde-robe pis un bon MacBook Pro sur ton bureau, tu es exactement le profil bêta qu'on adore : le Mini tient le fort 24/7 pendant que le MacBook Pro peut encaisser des runs d'évaluation ou de fine-tuning local en tandem sans jamais ralentir la cabane.
</Aside>

Il te faut aussi un compte [Cloudflare gratuit](https://dash.cloudflare.com/sign-up) (le niveau gratuit R2 de 10 Go sert aux sauvegardes chiffrées) pis une demi-heure tranquille. Tu n'as **pas** besoin d'IP statique, de domaine dédié, de compte Apple Developer ni d'aucun abonnement Sanctum.

## Le parcours en 6 étapes

<Steps>

1. **Lance l'installeur Sanctum.** Il installe Homebrew au besoin, `sanctum-cli`, `restic` pis Node.js signé :

   ```bash
   curl -fsSL https://sanctum.run/install.sh | bash
   ```

   Tu préfères vérifier le hash SHA-256 avant de coller un `curl | bash` (Windu approuve) ou passer direct par Homebrew? Installe directement le tap :

   ```bash
   brew install ogilthorp3/sanctum/sanctum-cli
   ```

   Sur Homebrew 5.x, accepte le tap tiers une seule fois avec `brew trust --formula ogilthorp3/sanctum/sanctum-cli`.

2. **Confirme que `sanctum` répond sur ton PATH.** Si le menu affiche `status`, `doctor`, `onboard`, `backup` et `chat`, t'es en business :

   ```bash
   sanctum --version
   sanctum --help
   ```

   <Aside type="tip">
     Un Mac neuf peut demander d'installer les Command Line Tools d'Apple. Laisse Apple finir pis relance la commande — l'installeur est idempotent.
   </Aside>

3. **Démarre l'onboarding interactif.** C'est le vrai baptême de feu, en cinq chapitres guidés :

   ```bash
   sanctum onboard --recipe family
   ```

   - **Your AI** range optionnellement tes clés **Claude** et **Gemini** dans le trousseau macOS. Saute cette étape si tu veux rouler 100 % local.
   - **Your Network** sonde un pont Bell, Firewalla et Orbi (facultatif sur un bureau de test).
   - **Your Data** configure Cloudflare R2 chiffré, lance une vraie sauvegarde pis restaure un fichier canari pour prouver l'aller-retour.

   Quand le panneau vert s'allume avec ton prénom, prends une capture d'écran.

4. **Installe le Dragon local et jase avec lui.** Ferme tes navigateurs lourds avant — le modèle 27B aime sa place sur un Mac de 32 Go :

   ```bash
   curl -fL -o sanctum-dragon.zip \
     https://github.com/Ogilthorp3/homebrew-sanctum/releases/download/dragon-1/sanctum-dragon-guest.zip
   unzip sanctum-dragon.zip
   cd sanctum-dragon-guest
   ./install.sh
   ./chat.sh
   ```

   Le premier lancement télécharge environ 15 Go. Tape `q` pour quitter ou `r` pour repartir à neuf.

5. **Passe le bilan de santé.** Les deux commandes suivantes doivent sortir propres d'un bout à l'autre :

   ```bash
   sanctum status
   sanctum doctor
   ```

   Tout ce qui vire jaune ou rouge t'indique exactement quelle ligne réparer. Zéro théâtre de faux vert.

6. **Déballe le studio bundle (si tu en as reçu un).** Lance `./install.sh` puis `./yoda.sh hello` pour entendre ton Mac parler en local, et `./council.sh` pour interpeller Windu, Qui-Gon, Cilghal, Mundi ou Mothma directement sur ton Dragon.

</Steps>

## À quoi s'attendre la première semaine

<CardGrid>
  <Card title="Jour 1" icon="rocket">
    Tu reçois une alerte quand la première sauvegarde quotidienne passe. Après ça, Sanctum se tait. Il a rien à te vendre.
  </Card>
  <Card title="Jours 2 et 3" icon="laptop">
    Jase au Dragon avec `./chat.sh`, jette un œil à `sanctum status` avec ton café. Moins tu penses à taper ces commandes, mieux ça roule.
  </Card>
  <Card title="Jours 4 à 7" icon="moon">

  </Card>
  <Card title="Quand ça pète (bêta!)" icon="approve-check-circle">

  </Card>

## Quelque chose a brisé? Dis-nous-le franchement

Le contrat est simple pis tient pas dans une licence de quarante pages : ta cabane te mentira jamais pour protéger tes sentiments. Si une lumière est verte sans preuve derrière, c'est du théâtre. Ouvre un billet sur le [formulaire bêta `sanctum-cli`](https://github.com/Ogilthorp3/sanctum-cli/issues/new/choose) avec ta sortie `sanctum doctor` (secrets caviardés) — on les lit tous.

Une fois que ton panneau vert te dit bonjour, explore [L'Architecture en 5 minutes](/qc/architecture/), jette un œil au [Guide des parents](/parents-guide/qc/) pour gérer les écrans en famille, ou retourne saluer [Tommy](/qc/).
