## Zero-RCE by construction, not by promise

Every distributed compute project eventually meets an attacker who tries to smuggle a shell command inside a job payload. Firewalls help, yet the only durable defense is refusing to accept or execute code at all.

The `sanctum hive swarm` protocol enforces four hard layers before a packet ever touches Metal silicon:

1. **Strict allowlist + zero-RCE payload guard:** Every `WorkPacket` is validated against a closed per-task key allowlist (`inference_map`, `eval_benchmark`, `diloco_step`, `pipeline_stage`), capped at 64 KiB, and rejected instantly if any nested field names an execution verb (`cmd`, `shell`, `exec`, `eval`, `script`, `path`), null byte, or `../` traversal sequence.
2. **Post-quantum domain-separated signatures:** Creators and workers sign canonical JSON manifests using `Ed25519 + NIST FIPS 205 SLH-DSA-SHA2-128s` (surviving every threat scenario documented in [Security](/operations/security/), including simultaneous RSA, ECC, and lattice collapse), with distinct domain prefixes so a signed packet can never replay as a project or result.
3. **Sandboxed local inference only:** Workers run `SwarmWorker` exclusively against local [`sanctum-mlx`](/architecture/sanctum-mlx/) over loopback mTLS (`:1337`) or deterministic benchmark evaluators — never spawning a subprocess and never writing outside the local workspace.
4. **Trust Zone isolation (`open_hive` vs `trusted_circle`):** Open Hive jobs handle public science, open evaluations, and shared open-weights LoRA rounds. `pipeline_stage` workloads are mathematically forbidden in `open_hive` because activation inversion attacks are real; private multi-Mac inference runs strictly inside an explicit `trusted_circle` of pinned public keys behind `sanctum-pq-terminator --psk-file`.

## Byzantine verification and DiLoCo federated LoRA

Never trust a stranger's answer. Not once.

For deterministic benchmarks and high-stakes synthesis, a project sets `--redundancy 3` so three distinct Macs claim independent TTL-bounded leases on the same packet (auto-requeued if a laptop sleeps mid-job). When quorum lands, the coordinator reconciles consensus, awards GPU-second credits to the matching majority, slashes the outlier's reputation (`-0.25`), and automatically quarantines repeat liars onto `probation` once reputation drops below `0.40`.

Federated LoRA training uses the same discipline through **DiLoCo** (Distributed Low-Communication Training):

- **Zero private data leaves any Mac.** Each node runs 100–500 local optimization steps on Apple Silicon and uploads only a signed outer-gradient `DiLoCoDelta` manifest (`delta_hash`, `num_samples`, `eval_loss_before`, `eval_loss_after`, `delta_l2_norm`).
- **Local improvement gate:** Any delta where `eval_loss_after >= eval_loss_before` is rejected on arrival before touching the round bucket.
- **Trimmed-median norm guard:** When three or more deltas arrive in a round, any poisoned gradient whose L2 norm exceeds `3.0x` the round median is filtered out and slashed before deterministic sample-weighted FedAvg mixing weights are emitted — ready to pass through the local [Champion Gate](/architecture/champion-gate/) before any node promotes the resulting adapter.

## Reciprocal compute credits — zero coins, zero cloud

Crypto "DePIN" grids drown real engineering in tokenomics, gas fees, and speculative noise. Sanctum borrows from BitTorrent instead.

Every verified packet and accepted DiLoCo delta credits the worker's `CreditAccount` with exact measured `gpu_seconds` while debiting the project creator by the same amount. Contributors who donate overnight Apple Silicon cycles rise to `vanguard` and `contributor` priority tiers so their own daytime burst projects schedule ahead of zero-contribution freeloaders — no blockchain, no wallet, no middleman.
