Every claim in Sanctum must cite a reproducible observation from disk. Latency and memory regress quietly without active gates. The unified [sanctum-benchmark](/reference/sanctum-cli) CLI guards performance and enforces physics bounds across [Sanctum MLX](/architecture/sanctum-mlx) and the operational estate.

## Usage

### 1. Run Standard Benchmark
Runs performance and capability benchmarks across all operational planes, records the run to `~/.sanctum/state/benchmarks/history.jsonl`, and prints the delta against the previous run:
```bash
sanctum-benchmark
```

### 2. Fast Smoke Benchmark
Runs fast iterations and 6-category smoke subset for rapid regression checking:
```bash
sanctum-benchmark --quick
```

### 3. Isolated Suite Run
Focus on a specific subsystem or capability suite:
```bash
sanctum-benchmark --suite carmack    # 26-task Carmack Olympics capability suite
sanctum-benchmark --suite laya       # System 1 reflex decision engine
sanctum-benchmark --suite thalamus   # Global Workspace endpoints
sanctum-benchmark --suite crm        # Privacy gate & firewall
sanctum-benchmark --suite bridge     # Edge SharePoint bridge
```

### 4. Progression & History View
Examine historical latency trends and throughput progression across git commits:
```bash
sanctum-benchmark --history 15
```

## Storage & Invariants

- **History Location**: `~/.sanctum/state/benchmarks/history.jsonl` (append-only, atomic writes).
- **Latest Pointer**: `~/.sanctum/state/benchmarks/latest.json`.
- **Environment Metadata**: Every record embeds git commits for `sanctum-config`, `sanctum-emergence`, `sanctum-crm`, along with CPU model (`Apple M4 Pro`) and daemon memory RSS.
- **Anti-Mock Fidelity Invariant**: Mocks, stubs, and hollow JSON returns are strictly forbidden in benchmarked workloads. `sanctum-benchmark` executes semantic discrimination probes before recording timing:
  1. *Dynamic Contrast Probe*: Opposing prompts (critical outage vs trivial banter) must generate divergent salience scores (`Δ ≥ 0.20`).
  2. *Domain Discrimination*: Distinct contexts (personal vs work) must activate opposing classifier heads with non-uniform probability distributions.
  3. *Physics Lower Bound*: A 149M-parameter transformer cannot complete a forward pass on unified memory in `< 3ms`. Latencies below this threshold immediately fail the run with a physics violation.
 
Automated benchmark runs gate every production release on Manoir Nepveu, anchoring performance claims to verifiable hardware telemetry.
