## The `Referrer-Policy` trap inside `:38883`

Cilghal's daemon answered `200 OK`. Yet its embedded tab failed. Probing `:8770/panel/` exposed the culprit in two response headers:

```text
referrer-policy: no-referrer
content-security-policy: default-src 'self'; frame-ancestors 'self' http://localhost:3344 app:
```

To frame loopback and tailnet web surfaces inside a `file://` Electron window without loosening renderer isolation, `ServiceIframe` routes requests through `httpProxy` on `127.0.0.1:38883/<base64url-origin>/panel/`. When the panel's JavaScript subsequently calls root-relative `fetch('/api/today')`, the browser hits `http://127.0.0.1:38883/api/today` — omitting the `<base64url-origin>` prefix and relying on `httpProxy` to recover the upstream origin from `req.headers.referer`. Because `cilghal-coach` emitted `Referrer-Policy: no-referrer`, Chromium stripped the `Referer` header on every XHR. The proxy saw `"api"` instead. It rejected the call with `HTTP 400`.

Stripping upstream `referrer-policy` on the loopback proxy, pairing it with a `SameSite=Lax` `__holocron_proxy_origin` fallback cookie, and binding an `unref()`'d ephemeral loopback port whenever a secondary instance finds `:38883` occupied eliminated both the `HTTP 400` failure and a subtle event-loop hang in `main-hardening-smoke.mjs` child processes.

## Calming the glass and uniting both languages

Host telemetry stood calm and green. Next came the renderer sweep. Walking every locked and unlocked destination with `agent-browser` turned up four final polish seams across the UI:

1. **Zero idle animation tax.** `HausBrainPanel` previously ran twenty infinite Framer Motion JavaScript loops (`repeat: Infinity`) across seven MOC hubs. Replacing continuous JS keyframe loops with crisp CSS hover transitions dropped idle renderer CPU to near zero, while recursive `~/.sanctum/memory` hydration restored live `RECENT EVENTS` and orbiting `+ leaves` notes around every hub. Ring-buffer layers (`events` and `archive`) trimmed to `100%` of cap now render calm green unless genuinely `over_cap`.
2. **Unmounting cleanly and crisp Council orbs.** Navigating out of the unlocked Digital Twin view tripped React's `ErrorBoundary` because a single braceless `useEffect(() => chatRef.current?.scrollTo(...))` implicitly returned Chromium's smooth-scroll `Promise` as a cleanup callback (`TypeError: destroy is not a function`). Wrapping the effect body in a block, deduplicating `ipcRenderer` stream listeners in `preload.js`, and replacing broken root-relative `/assets/*.png` tags in `CouncilChamber` with kyber radial-glow vector monoliths eliminated every runtime error and broken asset under `file://`.
3. **Whole-system unified memory & accurate fleet attribution.** Rather than displaying only Castellan's budgeted launchd subset (`mlx-coder` hiding the second `sanctum-mlx` binary), `get-system-memory` in `main.js` fuses `vm_stat`, `top`, `ps`, `memory_pressure`, and `:2189/status` across the full `64 GB` / `128 GB` physical pool — listing every running `sanctum-mlx` instance separately with its model and port (`Muse-Glimmer-30B-4bit :3301` and `Qwen3.8-27B-4bit :1337`), top OS consumers (`Lima VM`, `WindowServer`, apps), and wired/compressed kernel memory. Fleet matching compares executable basenames so `sanctum-castellan` never collides with `castellan-deadman` and `sanctum-chi` never collides with `sanctum-chitti`, while Jocasta's Archives window (`:6666`) injects `~/.sanctum/secrets/jocasta-crm-personal.token` on an isolated session partition.
4. **Complete Québécois French and English parity.** Every remaining English holdout on the French Status and Council surfaces — `YodaCard`, `HausHealthPanel`, `R2D2StatusTile`, `HausBrainPanel`, `SanctumStackPanel`, `CouncilChamber`, sidebar items, and Jocasta's opening chat bubble — now switches live through `i18n.tsx` without a reload, while keeping `yoda-port-drift-check.sh`'s `:8765` source contract intact.
