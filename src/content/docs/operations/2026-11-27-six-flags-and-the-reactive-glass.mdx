Six flags waited in the queue. Every one sat behind a portal built to hate headless browsers. Banking SPAs in Angular, Cloudflare-shielded billing pages, multi-portal tax notices, and expired aggregator tokens all greet Playwright with the same polite wall.

We stopped fighting the glass. Instead, we moved the workflow into the operator's real Safari window.

By the end of the sweep, all six flags were off the board. Four reusable tools landed in `openclaw-skills`. Better yet, the boundary between autonomous prep and human sign-off became code, not etiquette.

## Why headless automation hits a wall on real portals

Headless Chromium still earns its keep on public docs and unauthenticated apps (see [Agent Browser](/guides/agent-browser/)). Real financial and government portals play by different rules.

- **Trust lives in the live browser.** Passkeys, Touch ID, hardware-backed cookies, and Safari AutoFill stay inside the signed-in macOS session. Ephemeral profiles never see them.
- **Anti-bot walls are not bugs.** Cloudflare challenges and bank push-MFA exist to stop unattended scripts. Sanctum's rule never bends: no CAPTCHA bypass, no spoofed checks, and zero unattended clicks on payment or commit buttons.
- **Naive DOM scripts silently fail.** Assigning `input.value` on an Angular or React checkout form leaves the reactive control untouched. Validation stays red. The submit button stays dead.

That gap stalled [Qui-Gon](/agents/quigon/) and [Mundi](/agents/mundi/) for months. Agents either dropped raw links in the operator's lap or fought brittle scripts that snapped on the first French label.

```bash
# Probe any reactive form in the operator's active Safari tab
~/Projects/openclaw-skills/safari-session/tools/safari-form.py probe --match royalbank

# Stage non-commit fields in one roundtrip (commit buttons raise ValueError)
~/Projects/openclaw-skills/safari-session/tools/safari-form.py fill \
  --match synxis \
  --spec-json '{"fields":[{"id":"firstName","value":"Neo"}]}'

# Re-authenticate an expired Plaid Item without creating a duplicate link
python3 ~/Projects/openclaw-skills/plaid/tools/plaid-link.py \
  --label bank-primary --update --safari
```

<Aside type="caution">
  Never run `plaid-link.py` without `--update` on an institution that only needs a password or MFA refresh. A fresh Link token with `products` creates a second billed Item, resets your sync cursor, and leaves Mundi untangling phantom duplicates at midnight.
</Aside>

## The glass bell jar stays over the seal

The sharpest feature in `safari-form.py` is refusal. Every spec hits `assert_spec_safe()` before a byte of JavaScript reaches Safari. Pass a `click_safe` label with any commit, transfer, payment, or signature token in English or French, and the driver aborts locally with `ValueError`. Even inside `providers/rbc/provider.py`, staging stops cold on the filled form and returns readback JSON. Nothing clicks confirm.

Three habits made the pattern stick across every portal:

1. **Snapshot first, prune last.** Each Safari run saves a tab snapshot via `safari.sh snapshot` before touching Window 1. Once verified done, `safari.sh prune` closes only the tabs we added and leaves the operator's workspace untouched.
2. **Read the live DOM before blaming the script.** When a third-party bank payee form threw a generic technical error on a commercial destination account, `safari-form.py` surfaced the `<rbc-alert>` banner and field readback immediately. That proved the bank rail itself rejected commercial accounts — not our script, and not the French UI.
3. **Store verified portal topology on disk.** Guessing legal-entity routing wastes hours. We audited the live multi-entity portals directly and persisted clean structured state for [Mundi](/agents/mundi/), preserving the [Security](/operations/security/) line between read-only financial counsel and human-executed payments.

## Six flags folded, one line held

Automation brings the operator to the final pane in seconds. Discipline stops it an inch before the button. Every Council agent now shares the same contract: gather every read-only artifact, prefill every safe field, prove the readback from the live DOM, and stop at the glass bell jar. Only the human hand lifts the signet seal.
