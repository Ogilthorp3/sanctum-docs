A sentinel that reads yesterday's catalog reports yesterday's peace.

At 07:41 this morning, [Windu](/agents/windu/) upgraded the Tailscale add-on on Home Assistant Green (`0.30.3 -> 0.30.4`) and declared every runtime across `manoir`, `mbp`, `chalet`, and `yoda` current (`outdated_security_brew: []`). Every check was green. Four blind spots hid underneath that green.

## Four ways the watch went blind

| Blind spot | What was on disk | What Windu missed |
|---|---|---|
| **Frozen Homebrew index** | `HOMEBREW_NO_AUTO_UPDATE=1` ran without `brew update --quiet`, freezing Homebrew's JWS formula index | 9 outdated security formulae on `manoir` (`opencode`, `certifi`, `librsvg`, `harfbuzz`, `git-lfs`, `pycparser`, `gh`, `openjdk@17`, `python@3.15`), 10 on `mbp`, and 5 on `chalet` |
| **Seven-formula allowlist** | `SECURITY_BREW_FORMULAE` tracked only `certifi`, `cloudflared`, `nss`, `tailscale`, `unbound`, `go`, and `opencode` | `chalet` sat on unpatched `openssl@3` (`3.6.5 -> 3.5.9`), `libnghttp3` (`1.17.0 -> 1.18.0`), `libngtcp2` (`1.24.0 -> 1.25.0_1`), and `rust` (`1.99.0_1 -> 1.99.1`) |
| **Airgapped VM `apt` freeze** | `yoda` (`Ubuntu 24.04`) has no outbound route by design, so its `apt` lists never refreshed | `openssl` (`3.0.13-0ubuntu3.11 -> 3.0.13-0ubuntu3.16`) and `curl` (`8.5.0-2ubuntu10.11 -> 8.5.0-2ubuntu10.16`) sat five Ubuntu security updates behind, alongside `libssh-4`, `apparmor`, `ca-certificates`, and the `6.8.0-147` kernel |
| **Hardware-only LLM filter** | `ask_argon` restricted `device` to `orbi, firewalla, bell_hub, chalet`, and `names_this_gear()` returned `False` for `manoir`, `mbp`, `yoda`, and `green` | New software CVE headlines (Brotli C/Python decoders, LiteLLM pipeline hijack) could never page for compute nodes |

## Thawing the tap without touching pins

Passing an uninstalled formula name to `brew outdated --quiet` exits `1`, which previously caused Windu to discard the entire outdated list. Both `windu-threat-watch.py` and `windu-doctor.py` now refresh Homebrew's signed JWS index on a bounded TTL (`brew update --quiet`), read `brew outdated --json=v2`, and split the 37-formula security perimeter cleanly into `pinned == false` (auto-upgraded across `manoir`, `mbp`, and `chalet`) and `pinned == true` (preserved under [Upgrade Path](/operations/upgrade-path/)).

Every `manoir` upgrade immediately runs `sanctum-sunday-upgrade.sh --check-pins` so Qui-Gon, Yoda, Jocasta, Cilghal, and Mundi never wake up to a pinned runtime whose underlying dylib soname moved (`Pinned linkage: all pinned formulas link cleanly`). `1password-cli` stays excluded because swapping its binary voids desktop biometric authorization until a human is at the keyboard.

## Patching an airgapped VM without breaking the airgap

`yoda` runs host-only on `bridge100` with zero internet access. Giving it a standing proxy or NAT route would violate [The Airgap That Forgot Itself](/operations/2026-07-26-the-airgap-that-forgot-itself/). Leaving its `apt` cache frozen left `openssl` and `curl` five Ubuntu security releases behind.

Windu now opens a temporary, strictly allowlisted bridge that exists only for the seconds `apt-get` runs:

1. `manoir` binds an in-process `ThreadingHTTPServer` on `127.0.0.1:0` that permits **only** `GET` and `HEAD` requests matching `http://ports.ubuntu.com/ubuntu-ports/*` (`HTTP 403` on any other host, scheme, method, or path).
2. `ssh -R` forwards a loopback port into `yoda` (`ControlMaster=no`) while `apt-get` verifies Canonical's `ubuntu-archive-keyring.gpg` signatures and installs updates with `NEEDRESTART_SUSPEND=1`.
3. `nodejs` is held via `apt-mark hold` (and the retired May `nodesource.sources` is disabled) so `dpkg` cannot overwrite `/usr/bin/node -> /opt/node26/bin/node` (`v26.12.1`).
4. `openclaw-vmnet-ip.service` now carries `PartOf=systemd-networkd.service` so `10.10.10.10/24` on `lima0` survives `systemd-networkd` restarts during `dbus` and `systemd` upgrades.

As soon as `ssh` exits, the reverse tunnel and local listener close. Two hundred and thirteen `dpkg` package and trigger steps completed on `yoda`, `openclaw-gateway.service` stayed `active`, and `apt-get -s upgrade` returned zero pending packages.

The watchtower no longer grades itself against a frozen catalog. Every node refreshes its index before it speaks, and the airgap opens one verified keyhole at 07:40 before locking shut again.
